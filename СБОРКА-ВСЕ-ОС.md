# Сборка SoheiDesk под macOS, Windows и Linux

## Важная правда

| Где вы сейчас | Что можно собрать |
|---------------|-------------------|
| **Только Mac** | macOS `.app` / `.dmg` (у вас уже есть arm64; можно universal) |
| **Только Windows** | `.msi` / `.exe` |
| **Только Linux** | `.AppImage` / `.deb` |
| **GitHub Actions** | **все три сразу**, артефакты скачиваются с сайта |

С Mac **нельзя** честно получить Windows-установщик или Linux AppImage без CI, Docker-образа с Linux или отдельной машины.  
Это ограничение компиляторов и бандлеров, не «недоделанный SoheiDesk».

## Вариант A — GitHub Actions (рекомендуется для «все три ОС»)

1. Создайте репозиторий на GitHub (можно **private**).
2. Залейте код (когда будете готовы; до этого workflow уже лежит в проекте):

```bash
cd ~/Documents/Projects/SoheiDesk
git add .
git commit -m "SoheiDesk 0.4 multiplatform CI"
# привяжите remote и push — только когда сами решите
git remote add origin https://github.com/pinkprincess766/SoheiDesk.git
git push -u origin main
```

(Если remote уже добавлен — достаточно `git push`.)

3. На GitHub: **Actions → «Build all platforms» → Run workflow**.
4. Дождитесь зелёных job’ов **macOS / Windows / Linux**.
5. Внизу run’а → **Artifacts**:
   - `soheidesk-macos`
   - `soheidesk-windows`
   - `soheidesk-linux`

Файл workflow: [`.github/workflows/release.yml`](./.github/workflows/release.yml)

Ничего «магически» в Store не публикуется — только zip’ы артефактов на 30 дней.

## Вариант B — локально на каждой ОС

### Mac
```bash
./scripts/build-local.sh
# или
pnpm app:build
# universal (Intel + Apple Silicon), если установлен target:
pnpm tauri build --target universal-apple-darwin
```

### Windows (PowerShell / cmd в папке проекта)
```bash
pnpm install
pnpm app:build
```
Ищите: `src-tauri\target\release\bundle\msi\` или `nsis\`

Нужны: [Node](https://nodejs.org), [Rust](https://rustup.rs), [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) (обычно уже есть в Windows 10/11), Visual Studio Build Tools (C++).

### Linux (Ubuntu 22.04+)
```bash
sudo apt update
sudo apt install -y libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev \
  patchelf libssl-dev libgtk-3-dev libayatana-appindicator3-dev
pnpm install
pnpm app:build
```
Ищите: `src-tauri/target/release/bundle/appimage/` и `deb/`

## Что отдать пользователям

| ОС | Файл | Как поставить |
|----|------|----------------|
| macOS | `SoheiDesk_*.dmg` | Открыть → перетащить в Программы |
| Windows | `.msi` или setup `.exe` | Далее-далее-установить |
| Linux | `.AppImage` | chmod +x → двойной клик; или `.deb` → установить |

Пользователям **не нужны** `pnpm` и терминал — только готовый установщик.
