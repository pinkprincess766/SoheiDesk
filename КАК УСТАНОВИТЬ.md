# Как установить SoheiDesk

**Полная инструкция для обычных пользователей:**  
→ **[README.ru.md](./README.ru.md)**

Кратко:

1. Скачайте файл для вашей ОС:  
   **https://github.com/pinkprincess766/SoheiDesk/releases**  
2. Установите **без терминала** (как обычную программу).  
3. Mac: если «неизвестный разработчик» → **правый клик → Открыть**.  
4. Windows: если SmartScreen → **Подробнее → Выполнить в любом случае**.
