# SoheiDesk

**Программа для компьютера:** читать документы (PDF и другие), делать пометки, вести простой дневник работ, сохранять отчёты.

Вам **не нужно** уметь программировать.  
Вам **не нужно** открывать «чёрное окно» (терминал) и вводить команды.  
Вы скачиваете файл, устанавливаете программу и запускаете её **как обычное приложение** (как браузер или Word).

## 1. Что это такое простыми словами

SoheiDesk — это **одна программа на компьютере**, в которой можно:

| Задача | Что делать в SoheiDesk |
|--------|-------------------------|
| Открыть статью или файл | Раздел **«Ридер»** → «Открыть файл…» |
| Выделить текст / нарисовать | Панель справа в ридере |
| Записать, что сделали сегодня | Раздел **«Журнал»** |
| Сохранить отчёт в файл | Раздел **«Экспорт»** |
| Найти что-то по тексту | Раздел **«Поиск»** |

Программа работает **в основном без интернета**.  
Интернет нужен только для отдельных вещей (например, поиск статей по DOI или RSS-ленты).

## 2. Что вам понадобится

- Компьютер: **Mac**, **Windows** или **Linux**
- Место на диске: примерно **50–100 МБ** (плюс ваши файлы)
- Файл установки со [страницы Releases](https://github.com/pinkprincess766/SoheiDesk/releases)  

**Не нужны:** знание команд, Python, Node, «среда разработки».

## 3. Как скачать

1. Откройте в браузере:  
   **https://github.com/pinkprincess766/SoheiDesk/releases**  
2. Откройте **самый верхний** (новый) релиз.  
3. Внизу, в блоке **Assets** (файлы), скачайте файл **для вашей системы**:

| Ваш компьютер | Какой файл качать (примерно) |
|---------------|------------------------------|
| **Mac** (чипы M1 / M2 / M3 / M4 **или** Intel) | `SoheiDesk_…_universal.dmg` **или** `soheidesk-macos…zip` |
| **Mac** только Apple Silicon (если нет universal) | `SoheiDesk_…_aarch64.dmg` |
| **Windows** | файл `.msi` или `…setup.exe` / `soheidesk-windows…zip` |
| **Linux** | `.AppImage` или `.deb` / `soheidesk-linux…zip` |

> **Не знаете, Mac какой?**  
> Меню  → **Об этом Mac**.  
> Если «Чип» — Apple Silicon. Если «Процессор Intel» — Intel.  
> Файл **universal** подходит **и тем, и другим**.

4. Дождитесь окончания загрузки.  
5. Запомните, **куда** скачалось (часто папка **«Загрузки» / Downloads**).

## 4. Установка на Mac

### Шаг за шагом

1. В папке **Загрузки** найдите файл вида  
   `SoheiDesk_0.4.0_universal.dmg`  
   (цифры версии могут отличаться).
2. **Дважды щёлкните** по этому файлу.
3. Откроется небольшое окно с иконкой **SoheiDesk** и папкой **Программы** (Applications).
4. **Перетащите** иконку SoheiDesk **на** папку «Программы».
5. Дождитесь копирования.
6. Откройте **Finder → Программы** и найдите **SoheiDesk**.
7. **Дважды щёлкните** по SoheiDesk.

Готово. Можно закрепить в Dock: щёлкните правой кнопкой по иконке в Dock → **Параметры → Оставить в Dock**.

### Если Mac пишет: «не удаётся открыть, потому что от неизвестного разработчика»

Это **нормально**, если программа ещё не «подписана» в Apple.  
Вы не сделали ничего неправильного.

**Способ 1 (самый простой):**

1. Найдите SoheiDesk в **Программах**.  
2. **Правый щелчок** (или Control + щелчок) по иконке.  
3. Выберите **«Открыть»**.  
4. В окне предупреждения снова нажмите **«Открыть»**.  
5. В следующий раз достаточно обычного двойного щелчка.

**Способ 2:**

1. **Системные настройки** → **Конфиденциальность и безопасность**.  
2. Прокрутите вниз.  
3. Если есть кнопка **«Всё равно открыть»** рядом с сообщением о SoheiDesk — нажмите её.

### Если файл в `.zip`

1. Дважды щёлкните zip — macOS распакует.  
2. Если внутри `.dmg` — откройте его (инструкция выше).  
3. Если внутри `.app` — перетащите **SoheiDesk.app** в **Программы**.

## 5. Установка на Windows

1. Скачайте файл для Windows (`.msi` или установщик `.exe`).  
2. **Дважды щёлкните** по нему.  
3. Если Windows спросит «Разрешить этому приложению вносить изменения?» — **Да**.  
4. Нажимайте **Далее / Next** → **Установить / Install**.  
5. После установки запустите **SoheiDesk** из меню **Пуск** или с рабочего стола.

### Если Windows пишет: «Windows защитила ваш компьютер» (SmartScreen)

1. Нажмите **«Подробнее»**.  
2. Затем **«Выполнить в любом случае»**.  

Так бывает у программ без «сертификата Microsoft».  
Скачивайте **только** с официальной страницы Releases вашего репозитория.

## 6. Установка на Linux

Зависит от того, какой файл вам дали.

### Вариант A — AppImage (часто проще)

1. Скачайте файл `…AppImage`.  
2. Правый щелчок по файлу → **Свойства** → вкладка **Права**.  
3. Включите **«Выполнение файла как программы»** (Allow executing).  
4. Дважды щёлкните по файлу.

Если «не запускается» — попросите того, кто дал программу, помочь один раз с правами.  
(Иногда на Ubuntu нужен пакет `libfuse2` — это уже задача для техподдержки / админа.)

### Вариант B — .deb (Ubuntu / Debian)

1. Дважды щёлкните `.deb` **или** откройте через «Установка программ».  
2. Нажмите **Установить**.  
3. Запускайте SoheiDesk из меню приложений.

## 7. Первый запуск

После открытия вы увидите окно с **меню слева** (Ридер, Библиотека, Журнал…).

1. Нажмите **«Ридер»**.  
2. Нажмите **«Открыть файл…»**.  
3. Выберите любой PDF или текстовый файл на компьютере.  
4. Файл должен открыться в окне.

Если открылось — всё установлено правильно.

## 8. Как пользоваться (по шагам)

### 8.1. Открыть документ

1. Слева: **Ридер**.  
2. Кнопка **«Открыть файл…»**.  
3. Выберите файл.  

Поддерживаются, среди прочего: **PDF**, **Word (DOCX)**, **текст**, **Markdown**, **HTML**, иногда **EPUB**.

> Программа **не портит** ваш исходный файл.  
> Пометки хранятся **внутри SoheiDesk**, отдельно.

### 8.2. Пометки (выделение, комментарий)

1. Откройте документ.  
2. Справа панель инструментов.  
3. Выберите **«Выделение»** или **«Комментарий»**.  
4. Для текста: выделите мышью.  
5. Для PDF: можно нарисовать прямоугольник / перо (в зависимости от режима).

Пометки сохраняются сами. Закройте программу и откройте файл снова — они должны остаться.

### 8.3. Библиотека

**Библиотека** — список файлов, которые вы уже открывали через SoheiDesk.

- Можно открыть снова отсюда.  
- «Убрать» из библиотеки **не удаляет** файл с диска, только из списка программы.

### 8.4. Журнал (дневник)

1. Слева: **Журнал**.  
2. **«Новая запись»** или выберите **готовый шаблон**.  
3. Заполните поля и текст.  
4. Нажмите **«Сохранить»**.

Это удобно для заметок «что сделал», «что измерил», «что прочитал».

### 8.5. Экспорт (сохранить отчёт файлом)

1. Слева: **Экспорт**.  
2. Выберите запись журнала **или** период дат.  
3. Выберите формат (например Markdown, HTML…).  
4. **«Предпросмотр»** — посмотреть.  
5. **«Сохранить файл…»** — выбрать папку на компьютере.

### 8.6. Поиск

1. **Поиск**.  
2. Введите слово.  
3. **Найти**.  
4. Щёлкните по результату — откроется документ или запись.

### 8.7. Остальные разделы (по желанию)

| Раздел | Зачем |
|--------|--------|
| **Литература** | Подтянуть данные статьи по DOI / поиску (нужен интернет) |
| **Zotero** | Если пользуетесь программой Zotero — импорт списка |
| **RSS** | Ленты новостей журналов (нужен интернет) |
| **OCR** | Распознать текст с **картинки** (нужна отдельная программа Tesseract) |
| **Плагины** | Для продвинутых пользователей |
| **Настройки** | Тема, помощь, сетевой доступ «LAN» |

Если чем-то не пользуетесь — **можно просто не открывать**. Основное: **Ридер + Журнал**.

## 9. Частые проблемы

### «Программа не открывается» (Mac)

- Сделайте **правый щелчок → Открыть** (см. [раздел 4](#4-установка-на-mac)).  
- Убедитесь, что перетащили приложение в **Программы**, а не запускаете с «рабочего стола из dmg» после извлечения диска.

### «Windows заблокировала»

- **Подробнее → Выполнить в любом случае** (см. [раздел 5](#5-установка-на-windows)).  
- Скачивайте файл **только** с Releases этого проекта.

### «Не вижу свой файл»

- SoheiDesk **не сканирует** весь компьютер сам (это сделано для безопасности).  
- Всегда: **Открыть файл…** и выбрать вручную.

### «Пометки пропали»

- Файл **переименовали / перенесли / сильно изменили** — программа может считать его «новым».  
- Попробуйте открыть **тот же** файл через **Библиотеку**, если он там есть.  
- Не удаляйте данные приложения (см. [раздел 11](#11-безопасность-и-ваши-данные)).

### «Нет интернета / не работает DOI»

- Чтение PDF и журнал **работают без сети**.  
- DOI, arXiv, PubMed, RSS — **нужен интернет**.

### «OCR не работает»

- Нужно, чтобы на компьютере был установлен **Tesseract**.  
- Это отдельная установка; без неё SoheiDesk всё равно работает, просто без распознавания картинок.

### Программа «тормозит» на большом PDF

- Подождите загрузки.  
- Уменьшите масштаб (−).  
- Закройте другие тяжёлые программы.

## 10. Частые вопросы

**Это сайт или программа?**  
Программа на компьютере. После установки интернет для основной работы не обязателен.

**Нужен ли пароль / аккаунт?**  
Нет. Регистрация не требуется.

**Куда деваются мои заметки?**  
На **ваш** компьютер, в данные приложения. Они **не** улетают «в облако» сами.

**Можно ли на телефон?**  
Нет, сейчас только компьютер (Mac / Windows / Linux).

**Сломает ли мои PDF?**  
Нет. Исходные файлы программа **не перезаписывает** при обычной работе.

**Сколько это стоит?**  
Смотрите лицензию репозитория. Обычно для своей лаборатории/группы — как договорились с автором.

**Кому писать, если ничего не получается?**  
Тому, кто дал вам ссылку на Releases (преподаватель, коллега, автор репозитория).  
Приложите: **какая ОС**, **что нажали**, **точный текст ошибки** (скриншот).

## 11. Безопасность и ваши данные

- Данные (журнал, пометки, настройки) хранятся **локально** на вашем компьютере.  
- Раздел **«LAN share»** в настройках — это **по желанию** «показать журнал в локальной сети».  
  **Не включайте**, если не понимаете, зачем. И **не** открывайте это в интернет-кафе / чужой Wi‑Fi без необходимости.  
- Скачивайте установщик **только** с GitHub Releases **этого** проекта, не с случайных сайтов.
