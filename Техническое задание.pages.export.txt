## 📋 Итоговое ТЗ: SoheiDesk

### 1. Поддержка форматов («Сжирать» любой текст)

**На входе:**

- PDF (текстовый и сканированный — с OCR через Tesseract)
- DOCX, ODT (Microsoft Word, OpenOffice)
- TXT, RTF
- Markdown (`.md`)
- EPUB (простой, без DRM)
- HTML (локальные страницы)
- LaTeX (`.tex`) — как исходник, не только скомпилированный PDF

**На выходе (для экспорта):**

- Конвертация в **Typst**, **LaTeX**, **HTML**, **Markdown**, **DOCX**

---

### 2. Элементы редактирования и аннотирования

**Инструменты для работы с текстом (как в хорошем PDF-ридере):**

- **Выделение текста** (цветные маркеры)
- **Подчёркивание**, **зачёркивание**
- **Комментарии** (привязанные к выделенному фрагменту)
- **Рисование от руки** (для планшетов/стилусов или мыши)
- **Вставка фигур** (стрелки, рамки, кружки)
- **Вставка формул** (с поддержкой LaTeX-синтаксиса)
- **Текстовые заметки** прямо на полях (как в книге)
- **Режим «свободной руки»** — рисование поверх PDF/текста, как отдельный слой

**Важно:** все аннотации сохраняются **отдельно** от исходного файла (в SQLite), не портят оригинал и могут быть синхронизированы между устройствами.

---

### 3. Лабораторный журнал

**Структурированный дневник экспериментатора:**

- Возможность создавать **записи** с датой и временем
- Каждая запись — это **текст + прикреплённые файлы/спектры + ссылки на статьи**
- **Шаблоны** для разных типов работ (синтез, анализ, кинетика, измерение)
- Поддержка **вложений** — можно прикрепить файл спектра, и он автоматически открывается в ChromaTsvet
- **Поиск по записям** — по тексту, дате, тегам, прикреплённым файлам
- **Экспорт журнала** — за семестр/проект можно сгенерировать отчёт в формате Typst/LaTeX/HTML для сдачи

**Пример записи:**

```
📅 2026-07-21, 14:30
📌 Эксперимент №42 — синтез соединения X

Текст описания...
Прикреплён спектр: spectrum_42.csv → [Открыть в ChromaTsvet]
Прикреплённая статья: Иванов_2023.pdf → [Открыть]
Теги: #синтез #ик-спектроскопия #соединение-X
```

---

### 4. Конвертация текста в Typst / LaTeX / HTML

**«Чистая» конвертация с сохранением структуры:**

- **Из ридера** → экспорт текущего документа/заметок/статьи в:
  - **Typst** (современный аналог LaTeX, набирает популярность)
  - **LaTeX** (для публикаций в журналах)
  - **HTML** (для веба и презентаций)

**Умные фишки конвертации:**

- Автоматическое распознавание **заголовков**, **списков**, **таблиц**, **формул** в исходном тексте
- Преобразование аннотаций (выделений, комментариев) в сноски или маргиналии в целевом формате
- При экспорте — вставка привязанных спектров в виде изображений с подписями
- Генерация **библиографии** из импортированных внешних источников (DOI, Zotero)

---

### 5. Интеграция с внешними источниками

**Сбор и импорт литературы:**

- **Zotero** / **Mendeley** — импорт библиотеки статей
- **arXiv** — поиск и скачивание препринтов по ключевым словам
- **PubMed** — поиск по биомедицинским статьям
- **DOI-разрешатель** — по DOI автоматически подгружать метаданные (название, авторы, журнал, год)
- Импорт **RSS-лент** научных журналов — чтобы быть в курсе новых публикаций

**Экспорт цитирования:**

- Генерация библиографии в форматах **BibTeX**, **RIS**, **APA**, **GOST**
- Экспорт списка литературы для статьи или отчёта

## 🏗️ Архитектурные предложения (как вписать в твой стек)

| Компонент | Технология | Что делает |
|-----------|------------|------------|
| **Парсеры форматов** | Rust (`pdf-extract`, `docx`, `tantivy`, `pandoc` через обёртку) | Извлекает текст и структуру из любых форматов |
| **Редактор текста** | Vue 3 + компонент рич-редактора (`tiptap` или `prosemirror`) | Отображение текста, аннотации, выделения, рисование (через Canvas как слой) |
| **Лабораторный журнал** | SQLite (уже есть в ChromaTsvet) + новые таблицы | Хранение записей, тегов, привязок к файлам |
| **Конвертер** | Rust (крейты для генерации Typst, LaTeX, HTML) + вызов pandoc для сложных случаев | Экспорт в целевые форматы |
| **Интеграции** | HTTP-клиенты + парсеры (arXiv API, Zotero API, DOI) | Сбор статей и метаданных |
| **Связь с ChromaTsvet** | IPC (трубы/sockets) или вызов через команды | Открытие спектров из ридера в анализаторе |
| **Хранилище метаданных** | SQLite (расширить существующую `lib.sqlite`) | Аннотации, связи с спектрами, теги, закладки |

## 🎯 Итог: что это будет

**SoheiDesk** — это не просто «ещё один ридер». Это **рабочее место исследователя**, где:

- Статья → выделение → комментарий → привязка спектра → анализ в SoheiDesk → заметка в лабораторный журнал → экспорт в готовый отчёт.

Весь цикл исследования замыкается в одной экосистеме без переключения между десятком программ.
